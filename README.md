# Проект - ElectroChainAPI

## Описание

Бэкенд-часть SPA-приложения онлайн платформы-торговой сети электроники.
Проект реализует API для управления звеньями сети (Завод, Розничная сеть, ИП), с поддержкой аутентификации с помощью
JWT-токенов
и прав доступа для активных сотрудников.

## Требования

* Python 3.12 / Django / DRF
* PostgreSQL (База данных)

## Установка:

- Клонируйте репозиторий:

```
git clone git@github.com:mariyakhrustal/ElectroChainAPI.git
```

- Установите зависимости:

```
pip install -r requirements.txt
```

## Инструкция по запуску

### 1. Настройка переменных окружения

Создайте в корне проекта файл `.env` и заполните его, используя в качестве примера файл `.env_sample`.

### 2. Проверка работоспособности сервисов

Для проверки работоспособности API выполните:

```
python manage.py runserver
```
